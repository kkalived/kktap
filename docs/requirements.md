# 用户需求文档

## 项目概述

Tapp 是一款运行在 Windows 电脑上的电子便利贴软件。用户可以像使用真实便利贴一样，在屏幕上贴多张便利贴，用于记录文字、展示图片。

## 功能需求

### 1. 多张便利贴
- 屏幕上可同时存在多张便利贴
- 便利贴可拖到屏幕任意位置
- 最多 3 张可以重叠放置在一起，形成「便签堆」
- 重叠后，下层便利贴右侧露出边缘，点击边缘可像翻书一样翻到那一页

### 2. 文字编辑
- 点击便利贴即可打字
- 输入内容自动保存，不丢失

### 3. 图片展示
- 便利贴上可以显示图片
- 支持从本地文件夹选择图片上传
- 支持通过截图功能将截图直接放在便利贴上

### 4. 全局截图
- 默认快捷键：Ctrl+Alt+Z
- 软件运行期间，在任何界面按下快捷键即可截图
- 截图方式：框选屏幕区域
- 截图完成后自动生成一张新便利贴，上面显示截图内容
- 按 Esc 可取消截图
- 快捷键可在设置中更换

### 5. 右键菜单
- 右键便利贴空白处弹出菜单，包含：
  - 新建便利贴
  - 插入图片
  - 查看历史记录
  - 删除当前便利贴
  - 设置（快捷键修改等）

### 6. 删除与恢复
- 右上角 X 按钮或右键菜单均可删除
- 删除的便利贴进入历史记录（回收站）
- 可从历史记录中恢复或永久删除

### 7. 调整大小
- 拖拽便利贴边缘或角落可调整大小

### 8. 数据持久化
- 关闭软件后，所有便利贴内容、位置、大小不丢失
- 重新打开软件自动恢复到上次的状态

## UI 设计要求

- 简洁直观，不要复杂
- 主色调：淡黄色，仿真实便利贴
- 便利贴略带倾斜，有阴影效果
- 参考真实便利贴的视觉风格

## 技术约束

- 运行平台：Windows 11
- 用户非技术人员，需提供简单的 .exe 安装方式
