# 设计规范

## 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 便利贴底色 | `#FFF9C4` | 淡黄色，仿真实便利贴 |
| 便利贴边缘 | `#E0D6A0` | 稍深的黄色，用于露出边缘的分隔线 |
| 文字颜色 | `#333333` | 深灰，保证可读性 |
| 删除按钮悬停 | `#E53935` | 红色，仅悬停时显示 |
| 阴影 | `rgba(0,0,0,0.12)` | 轻微阴影 |
| 截图选区边框 | `#2196F3` | 蓝色 2px 虚线 |
| 截图选区填充 | `rgba(33,150,243,0.1)` | 极淡蓝色 |
| 右键菜单背景 | `#FFFFFF` | 白色 |
| 右键菜单悬停 | `#F5F5F5` | 浅灰 |

## 阴影

```
box-shadow: 2px 3px 10px rgba(0, 0, 0, 0.12);
```

## 倾斜角度

每张便利贴随机 -1.5° 到 1.5° 之间的旋转角度，模拟随手贴上的效果。

## 翻页动画

- 类型：CSS 3D `perspective` + `rotateY`
- 时长：500ms
- 缓动：`ease-in-out`
- 视角距离：`perspective: 1200px`
- 翻转角度：`rotateY(-110deg)` 翻出，`rotateY(90deg)` → `rotateY(0deg)` 翻入

## 交互反馈

| 操作 | 反馈 |
|---|---|
| 悬停露出边缘 | 边缘颜色加深 8% |
| 悬停关闭按钮 | 按钮变红 |
| 拖拽便利贴 | 阴影加深 |
| 缩放便利贴 | 实时跟随鼠标 |
| 右键菜单出现 | fade-in 150ms |
| 删除便利贴 | fade-out 200ms |
