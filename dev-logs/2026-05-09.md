## Bug 修复

### 启动崩溃
- [x] 托盘图标缺失 → 图标文件不存在导致 `new Tray()` 崩溃
  - 修改 trayManager.js：图标缺失时用 nativeImage 动态生成 16×16 淡黄色备用图标
  - 运行 generate-icons.js 生成 icon.png / icon.ico / icon-tray.png

### 图片无法显示
- [x] data URI 方式不可靠 → 改为 `file:///` 绝对路径
  - `files:open-image` 返回 `file:///C:/Users/.../images/xxx.png`
  - `screenshotService.js` 同样使用 `file:///` URL 存入 img 标签
- [x] Electron 安全策略阻断 `file://` 加载 → 所有 BrowserWindow 加 `webSecurity: false`
  - windowManager.js、main.js（历史/设置窗口）、trayManager.js

### 截图问题
- [x] 截图选区无法自由选择大小 → 去掉 `fullscreen: true`，改用显式屏幕尺寸 + CSS background
- [x] 截图后自动创建新便利贴 → 改为插入到当前最上层活跃便利贴
  - windowManager.js 新增 `focus` 事件跟踪 `lastFocusedStackId`
  - screenshotService 优先插入活跃便利贴内容末尾 → 刷新窗口

### 新建便利贴位置
- [x] 新建出现在屏幕正中间 → 改为覆盖在当前便利贴之上
  - noteStore.js `createStack` 支持 overridePosition 参数
  - IPC handler 从 `event.sender` 获取调用方窗口坐标

### 右键菜单
- [x] 菜单超出便利贴边界不显示 → 显示前测量宽高，超出右/下边界时自动偏移

### 便利贴缩放
- [x] 只有一个 14px 角手柄 → 添加 4 边 + 4 角共 8 个缩放手柄（resize-edge / resize-corner）

### 图片间距
- [x] 图片与上下文字间距过大 → 去掉固定高度 wrapper，改用 JS 读图片原始尺寸按比例设初始大小
  - `getImageSize()` 读取 naturalWidth/naturalHeight
  - wrapper 初始宽度最大 260px、高度按比例
  - CSS `vertical-align: top` 消除 inline-block 底部空隙
- [x] 图片渲染后 wrapper 留白 → `resize: both; overflow: hidden;` + `object-fit: contain`

### 图片文字分离
- [x] 图片在独立 `.note-images` 区，无法在图片下方打字
  - 合并到同一个 contentEditable 区域
  - 图片容器设 `contenteditable="false"`（图片不可编辑，但周围可打字）
  - 更新 `getRenderableContent` 去重逻辑适配 wrapper + 裸 img 两种格式
